# daisy-business-demo

Daisy Business Solutions - Enterprise B2B technology powerhouse website demo.

## Features
- **Authentic Daisy Design**: Full reproduction of Daisy Business Solutions web presence.
- **Eight Business Divisions**: Connectivity, Telecoms, IT Managed Services, Software, Security, Print & Document, Energy & Solar, and Business Finance.
- **Interactive Service Wheel**: 8-division animated orbital service wheel with live routing hotspots.
- **Client Reviews Marquee**: Continuous dual-row infinite marquee featuring 38 verified client reviews across South Africa, responsive 4-cards-per-row desktop layout, and pause-on-hover interaction.
- **Modern Tech Stack**: Next.js 16 (App Router), Tailwind CSS v4, Lucide Icons.

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
